Créditos y fuentes de datos

Este producto usa la API de TMDB, pero no está respaldado ni certificado por TMDB. This product uses the TMDB API but is not endorsed or certified by TMDB.

  • TMDB — catálogo, pósters, reparto y tendencias.
  • JustWatch — datos de disponibilidad en plataformas, entregados a través de TMDB.
  • YouTube — los tráilers se reproducen con su reproductor incrustado.
  • Plyr — reproductor de video (licencia MIT).
  • Real-Debrid, Jellyfin/Emby y VLC — opcionales; solo se usan si tú los configuras.
Privacidad
  • Zynora no tiene cuentas, publicidad ni analíticas propias. Tus listas, gustos y ajustes se quedan en este dispositivo.
  • Cuando buscas o exploras, tus consultas se envían a TMDB usando tu credencial. Al abrir un tráiler, YouTube recibe esa solicitud.
  • Tu credencial de TMDB, el token de Real-Debrid y los datos de tu servidor se guardan solo aquí y nunca se incluyen en respaldos ni exportaciones.
  • El reproductor se descarga de cdn.plyr.io al abrir la app.
  • Si desinstalas la app, estos datos se borran. Haz un respaldo antes desde Mis listas.

Conecta
TMDB

Introduce tu credencial de TMDB para activar tendencias y búsquedas reales en este navegador.

La credencial se guardará únicamente en el almacenamiento local de este navegador para este prototipo. No la compartas ni uses este método en una web pública.

Puedes encontrar las credenciales en TMDB → Settings → API. La aplicación solicita datos públicos del catálogo. El despliegue final debe usar un backend y seguir las condiciones de TMDB.
